# A minecraft pvp plugin for minecraft server version 1.8.8

## Mini games

- The Bridge
- SkyWars
- BedWars
- More...

## Features

- Inventory editor in lobby to customize loadouts

### The Bridge

- 1v1, doubles duels
- Resetting maps after each game
- Customizable kits
- No fall damage
- No hunger
- Scoreboard with player scores and game time

Default kit

1. Iron sword x1
2. Bow x1
3. Arrow with cooldown 3 seconds, respawns after shooting
4. Blocks x128
5. Diamond Pickaxe with efficiency 2 x1
6. Golden apple x8

Notes: Golden apples instant heal all the health. If it is the first apple consumed, it will gain the player absorption hearts.

Players are dressed in leather armor with the color of their team. There are two teams: Red and Blue.
The player scores a point by jumping in to the opponent's goal. The first player to reach 5 points wins the game.
